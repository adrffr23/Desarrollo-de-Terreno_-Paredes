# Desarrollo de Terreno - Unity
Abrir el proyecto con Unity 6.3 LTS o una versión compatible.

## Descripción

Este proyecto consiste en la creación de una escena 3D en Unity utilizando herramientas de diseño de terrenos, texturas, assets, iluminación y objetos personalizados.

## Características principales

- Terreno modelado con herramientas de Unity Terrain.
- Aplicación de texturas.
- Modificación del terreno.
- Uso de assets para casas, molino, árboles, carretas y decoración.
- Colocación de al menos 10 cubos integrados como cajas dentro de la escena.
